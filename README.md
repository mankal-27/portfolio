# 🌐 Manjunath Kalkutagi — Developer Portfolio

A **modern, responsive portfolio website** built with **React + Vite + Tailwind CSS**, showcasing my projects, experience, and skills.
Deployed using **GitHub Pages**.

* ⚛️ **React** (Vite)

## ⚙️ Local Setup

### 1. Clone the repo

```bash
git clone https://github.com/mankal-27/portfolio.git
cd portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the dev server

```bash
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🌍 Deployment

### Build & Deploy

```bash
npm run deploy
```

This command builds your project and pushes it to the `gh-pages` branch.
Then enable **GitHub Pages** in your repo settings (branch: `gh-pages`).

### Manual Build

```bash
npm run build
npm run preview
```
